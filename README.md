# 🎓 Student Management System

A Full Stack CRUD application built using React, FastAPI, and MySQL.

## 🚀 Tech Stack

### Frontend
- React
- Vite
- JavaScript

### Backend
- FastAPI
- Python

### Database
- MySQL

---

## Features

- Add Student
- View Students
- Update Student
- Delete Student

## Installation

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend

```bash
cd frontend/react-learning
npm install
npm run dev
```
